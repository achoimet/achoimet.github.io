# Trésorine pages for techomi-forge.com/tresorine/

Source of truth: `docs/site/` in the Trésorine repo (achoimet/tresorine).

The Techomi Forge site (achoimet/achoimet.github.io) is a Vite build deployed to `gh-pages`.
Keep these files in the site project's `public/tresorine/` folder, otherwise a deploy replaces
the branch and removes them, breaking the privacy policy URL a Play listing will use.

Screenshots come from the debug build with a fictional household vault (no real data).
