# LiftOnly pages for techomi-forge.com/liftonly/

Source of truth: `docs/site/` in the LiftOnly repo (achoimet/replock).

The Techomi Forge site (achoimet/achoimet.github.io) is a Vite build deployed to `gh-pages`.
Keep these files in the site project's `public/liftonly/` folder (and the redirect pages in `public/replock/`), otherwise a deploy replaces
the branch and removes them, breaking the privacy policy URL used by the Play listing.
